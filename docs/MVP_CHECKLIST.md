# MVP implementation checklist

- [x] Select a folder and refresh its contents
- [x] Display files and folders in an expandable multi-select tree
- [x] Preview and safely move selected files
- [x] Preview and safely rename selected files with text or date/time presets
- [x] Edit modified, accessed, and (on Windows) created timestamps
- [x] Continue batch operations after individual failures and show results
- [x] Persist the last selected folder and window geometry
- [x] Add automated tests for file-operation logic
- [x] Document setup, usage, limitations, and planned features
