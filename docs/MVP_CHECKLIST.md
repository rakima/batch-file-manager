# MVP implementation checklist

- [ ] Select a folder and refresh its contents
- [ ] Display files and folders in an expandable multi-select tree
- [ ] Preview and safely move selected files
- [ ] Preview and safely rename selected files with text or date/time presets
- [ ] Edit modified, accessed, and (on Windows) created timestamps
- [ ] Continue batch operations after individual failures and show results
- [ ] Persist the last selected folder and window geometry
- [ ] Add automated tests for file-operation logic
- [ ] Document setup, usage, limitations, and planned features
