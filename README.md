# Batch File Manager

指定したフォルダ配下のファイルをツリーで確認し、複数ファイルの移動、リネーム、タイムスタンプ変更をまとめて行うWindows向けデスクトップツールです。実際にファイルを変更する前に、操作内容を一覧で確認できます。

## 主な機能

- フォルダ配下のファイル・フォルダを展開可能なツリーで表示
- ファイル名、種別、更新日時、サイズを表示
- Ctrl / Shiftを使った複数ファイル選択
- 指定フォルダへの一括移動
- 先頭、拡張子の前、末尾への文字列追加による一括リネーム
- `YYYYMMDD`、`YYYY-MM-DD`、`YYYYMMDD_HHmmss`、`HHmmss` の現在日時プリセット
- 更新日時・アクセス日時、およびWindows上での作成日時変更
- 実行前プレビューと確認ダイアログ
- 同名ファイルの上書き防止、ファイル単位のエラー処理、実行結果ログ
- 操作後の自動更新、前回選択フォルダとウィンドウサイズの保存

削除機能はありません。

## 必要環境

- Windows 10 / 11
- Python 3.11以上（Tkinterを含む標準的なPythonインストール）

実行時に外部パッケージは使用しません。

## 実行方法

リポジトリ直下で次を実行します。

```powershell
python -m pip install -e .
python -m batch_file_manager
```

インストール後は、次のコマンドでも起動できます。

```powershell
batch-file-manager
```

### 基本操作

1. 「フォルダを選択」で管理対象を開きます。
2. ツリーでファイルを選択します。複数選択には Ctrl または Shift を使います。
3. 右側のタブで移動、リネーム、またはタイムスタンプ変更を設定します。
4. 各タブの「プレビュー」ボタンで変更内容を確認します。
5. 画面下の「実行」を押し、確認ダイアログで承認します。
6. 右下のログでファイルごとの結果を確認します。

設定は `%APPDATA%\BatchFileManager\settings.json` に保存されます。

## テスト

標準ライブラリの `unittest` でテストできます。

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -v
```

## exe化について

GUI、ファイル操作、設定管理を分離し、`batch_file_manager.app:main` を単一の起動点にしています。将来PyInstallerなどを導入する場合も、この起動点を指定してパッケージ化できます。現時点では不要な依存を避けるため、exe生成ツールは追加していません。

## 現在の制限事項

- ドラッグ＆ドロップ移動は未実装です。移動タブから移動先を指定します。
- 操作対象はファイルのみで、フォルダ自体の移動・リネームには対応していません。
- Undo、コピー、削除には対応していません。
- ツリーは選択フォルダ配下を一度に読み込むため、非常に大きなフォルダでは表示に時間がかかる場合があります。
- Linux/macOSでは更新日時とアクセス日時を変更できますが、作成日時の変更はWindows専用です。
- 作成日時と他の日時を同時変更した際に作成日時だけ失敗すると、先に更新された日時は元に戻りません。結果ログに失敗として表示されます。

## 今後追加予定の機能

- 正規表現リネーム、文字列置換、連番付与、拡張子変更
- ファイルコピー、条件選択、検索・絞り込み
- Undoと操作履歴の永続化
- ドラッグ＆ドロップによる移動
- 大規模フォルダ向けの遅延読み込み
- PyInstallerによるWindows向けexe配布

## 構成

```text
src/batch_file_manager/
├── app.py                     # Tkinter GUIと画面制御
├── models.py                  # 操作計画・結果などのデータモデル
└── services/
    ├── file_operations.py     # プレビュー生成とファイル操作
    └── settings.py            # JSON設定の読み書き
tests/                         # ファイル操作・設定管理のテスト
docs/MVP_CHECKLIST.md          # MVP実装チェックリスト
```
